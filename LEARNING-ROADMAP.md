# Integrated Technology Mastery Roadmap

## Goal
Build practical professional competence across software engineering, cloud, data analytics, and productivity systems.

## Learning sequence
1. Digital foundations: Git, GitHub, Excel, ChatGPT, Notion, Obsidian, Google Calendar.
2. Programming foundations: Python, JavaScript, SQL.
3. Analytics: advanced Excel, Power BI, Tableau.
4. Web development: Node.js, React.js, APIs.
5. Cloud: Microsoft Azure, deployment, security, monitoring.

## Project portfolio
- Personal finance dashboard: Excel, SQL, Power BI
- Business performance dashboard: Python, SQL, Tableau
- Inventory management application: React, Node.js, SQL

- Cloud-hosted application: React, Node.js, Azure
- Personal life operating system: Notion, Obsidian, Google Calendar

## Learning standards
For each technology:
- Learn concepts and terminology.
- Complete guided exercises.
- Build an independent project.
- Document the work.
- Publish relevant code to GitHub.
- Review, refactor, and improve.
- Demonstrate the skill with a working artifact.
